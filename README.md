# タイ語えほん（雛形）

タイの民話を絵本形式で読みながらタイ語を学べる学習アプリの雛形です。React + Vite で構築しています。

対象は小学校高学年くらいの子供、タイ語は初学者向け（文字は少しずつ、ローマ字/カタカナの発音表記を併記）を想定しています。

## セットアップ

```bash
npm install
npm run dev
```

## 構成

```
src/
  stories/
    story01.json      物語データ（最小限のダミー・プレースホルダー）
  components/
    StoryViewer.jsx    絵本ビューア（未実装。TODOコメント参照）
    Review.jsx          振り返り（未実装。TODOコメント参照）
  App.jsx               物語データの読み込み・コンポーネントの土台
public/
  stories/story01/       物語ごとの画像・音声ファイルの配置先（現在は空）
```

各コンポーネント・スタイルファイルは中身が最小限の雛形（骨組みのみ）で、実装すべき内容はファイル冒頭の `TODO:` コメントに書かれています。

## 物語データの追加方法

### 1. JSON ファイルを作成する

`src/stories/storyXX.json` として、以下の形式でファイルを作成します（`story01.json` はダミーデータなので、内容を実データに差し替えるか、新しい番号でコピーして使ってください）。

```json
{
  "id": "story01",
  "title": "物語のタイトル",
  "titleThai": "タイ語のタイトル（任意）",
  "source": "出典（実在するタイの民話名など）",
  "pages": [
    {
      "id": 1,
      "text": "むかしむかし、村はずれに{{gongsai:ご先祖さま}}を祭るお堂がありました。",
      "thai": "กาลครั้งหนึ่ง ที่ชายหมู่บ้านมี{{gongsai:ศาลบรรพบุรุษ}}อยู่หลังหนึ่ง",
      "thaiReading": "ローマ字/カタカナ表記の読み方（任意）",
      "image": "/stories/story01/page01.png",
      "audioJa": "/stories/story01/page01_ja.mp3",
      "audioThai": "/stories/story01/page01_th.mp3"
    }
  ],
  "annotations": [
    {
      "id": "gongsai",
      "word": "ご先祖さま",
      "categories": {
        "lifestyle": "タイの家庭には祖先を祀るお堂があり、日々お供えをする習慣がある。",
        "values": "祖先を敬う気持ちは、タイの人々にとって大切な価値観のひとつ。"
      }
    }
  ],
  "review": [
    {
      "id": "review01",
      "annotationId": "gongsai",
      "image": "/stories/story01/review01.png",
      "word": "บรรพบุรุษ",
      "reading": "ローマ字/カタカナ表記の読み方（任意）",
      "meaning": "ご先祖さま",
      "audio": "/stories/story01/review01.mp3"
    }
  ]
}
```

#### 本文中の単語タップ（太字）について

- `pages[].text` / `pages[].thai` の本文中で `{{id:表示テキスト}}` という記法を使うと、`表示テキスト` の部分が本文中で太字・タップ可能になります。`id` は `annotations[].id` と対応させてください。
- 本文中の重要な単語だけにこのマーカーを付けてください（全部の単語を太字にする必要はありません）。
- `text`（日本語）と `thai`（タイ語）で別々にマーカーを付けられます。日本語だけ・タイ語だけに付ける、両方に付けて同じ `id` を指す、なども可能です。
- マーカーが付いていない本文には何もマークアップを書かなくてよく、通常のプレーンテキストのままで構いません。

#### `annotations`（単語の詳細カード）について

- 太字をタップしたときに開く詳細カードのデータです。カードの中身は「暮らし」「ことば」「価値観」の3カテゴリ（`categories.lifestyle` / `categories.language` / `categories.values`）で固定です。
- 該当する情報がないカテゴリはキーごと省略して構いません（上の例では `language` を省略しています）。空欄をUI側でどう扱うか（非表示にする／「情報なし」と表示する）は実装時に決めます。
- `annotations[].id` は物語内で一意にしてください。将来のコレクション機能（フェーズ2で予定。下記「単語コレクション機能の下地について」参照）で、タップした単語を記録するためのキーとして使う想定です。
- カードの閉じ方（×ボタン／カード外タップ／両方）は未定のため、実装側はどちらにも対応できる作りにしておいてください。

#### `review`（振り返りフラッシュカード）について

- 振り返り画面はクイズ形式ではなく、フラッシュカード形式です。表面が `image`（絵）、裏面が `word`・`reading`・`meaning`（単語・読み方・意味）です。
- `annotationId` は対応する本文中の単語の `annotations[].id` です（任意項目。無くてもよい）。
- 絵本を最後まで読み終えたら、ボタン操作なしで自動的にこの振り返り画面へ遷移する想定です。

#### 任意項目まとめ

- `thai` / `thaiReading` / `titleThai` / `annotations` / `annotations[].categories.*`（各カテゴリ） / `review[].reading` / `review[].annotationId` は任意項目です。無い場合はその部分の表示・機能が省略されます。
- 1話あたり3〜5ページ程度を目安にしてください。
- `review` はその物語の振り返り（フラッシュカード）に使う単語リストです。

### 2. 画像・音声ファイルを配置する

`public/stories/storyXX/` フォルダの下に、JSON内の `image` / `audio` に指定したパスと同じファイル名で配置してください。

```
public/stories/story01/
  page01.png
  page01_ja.mp3
  page01_th.mp3
  page02.png
  page02_ja.mp3
  page02_th.mp3
  ...
  review01.png
  review01.mp3
  ...
```

- イラスト担当者が後から画像・音声ファイルを追加する運用を想定しています。ファイル未配置時の表示（プレースホルダー表示、音声ボタンの非表示など）は `StoryViewer.jsx` 側で今後実装予定です（TODOコメント参照）。
- 音声は日本語・タイ語で別ファイルです（`_ja` / `_th`）。日本語・タイ語はそれぞれ独立して表示オン/オフ・再生/停止ができる想定なので、どちらか一方しか用意できていない場合でも構いません。

### 3. アプリに読み込ませる

`src/App.jsx` は現状 `story01.json` を直接 import する最小限の雛形です。複数話に対応する場合の読み込み方法（一覧画面など）は今後の実装課題です。当面は物語一覧画面を作らず、1話固定で表示する方針です（`App.jsx` 冒頭の TODO コメント参照）。

### 4. 単語コレクション機能（フェーズ2）の下地について

- コレクション画面・UI自体は今回のスコープ外（フェーズ2で対応予定）です。
- ただし、タップした単語をあとから記録できるように、`annotations[].id` を物語内で一意なキーとして設計しています。将来的には、例えば以下のような形でタップ履歴をローカルに保存できることを想定しています（**未実装・イメージ例**）。

```json
{
  "collectedWords": [
    { "storyId": "story01", "wordId": "gongsai" }
  ]
}
```
